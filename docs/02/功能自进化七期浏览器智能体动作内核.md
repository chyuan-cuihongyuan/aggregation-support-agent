# 功能自进化七期：浏览器智能体动作内核（工单 0339-0346）

> 七期 [0302 地图](../../../issues/0302-wayfinder-map-capability-self-evolution-7.md) AQ 簇收官（聚合 browser 新域）。借鉴 browser-use 114.6K（动作空间/agent loop/错误恢复）、microsoft/playwright 96.1K（动作模型/选择器/accessibility snapshot）、puppeteer 95.6K（录制回放/存证），stars 经 GitHub API 2026-09-14 认证核实。浏览器驱动走 **BrowserDriverPort 端口**（进程内假实现+录制器，真实 CDP/Playwright 驱动挂雾 0302），全部纯函数内核，零外部依赖。

## 一、八票能力面

| 工单 | 能力 | 内核 |
|------|------|------|
| 0339 AQ1 | 动作模型 | BrowserActionVO 六类动作（navigate/click/type/scroll/extract/wait）+ ActionValidator：必填校验/限幅（scroll≤10000、wait≤30000）/url scheme 白名单/未知类型拒绝，批量错误带序号路径 |
| 0340 AQ2 | 页面状态快照 | PageSnapshotVO（url/title/时刻/元素清单 role+name+selector+rect+enabled+editable）+ SnapshotSummarizer：role 分组计数+可编辑清单+截断标注；serialize/deserialize 往返一致 |
| 0341 AQ3 | 元素定位器 | ElementLocator 五策略依序回退：selector 精确→片段包含→文本包含（大小写折叠）→role+name→index 兜底；唯一命中/多候选 AMBIGUOUS/零命中 MISS/越界 MISS |
| 0342 AQ4 | 任务执行引擎 | BrowserTaskEngine：动作序列逐步执行（驱动端口）+校验过闸+步级记录（摘要/状态/耗时/快照摘要）；失败中止留上下文（动作+快照+错误） |
| 0343 AQ5 | 结构化抽取器 | StructuredExtractor：字段 schema（text/number/link+多值/必填）→role+name 匹配提取→类型转换校验，缺失/类型不符清单 |
| 0344 AQ6 | 模板与回放 | TemplateInstantiator：{{param}} 占位替换（未声明占位/缺参/残留占位三重拒绝）；browser_task_template 第 19 表双方言 DDL + 守卫 |
| 0345 AQ7 | 审计存证端口 | BrowserAuditPort（动作日志+截图存证）+ InMemoryBrowserAudit（占位实现，evidence 存摘要）；引擎集成 recordRun 自动登记 |
| 0346 AQ8 | 失败恢复 | RecoveryPolicy 三级链：RETRY（幂等白名单 navigate/scroll/extract/wait）→SKIP（skippable）→RELOCATE（文本重定位重放）；恢复点续跑 + 恢复轨迹留痕 |

## 二、DDL 与端口

- 聚合库第 19 表 `browser_task_template`（name 唯一/parameters JSON/actions_json/tenant），双方言同步追加，应用层维护 update_time。
- 端口：BrowserDriverPort（真实浏览器驱动挂雾，假实现确定性测试）、BrowserAuditPort（真实截图存证由 infrastructure 演进）。

## 三、测试与回归

- 域单测 15 例（AQ1 3 / AQ2+AQ3 5 / AQ4+AQ7+AQ8 4 / AQ5+AQ6 3）+ DDL 守卫 2 例，全部绿。
- 关键确定性验证：定位器五策略回退与歧义消解、序列化往返重放一致、失败即停快照留痕、三级恢复链逐级触发与轨迹、模板三重拒绝。
