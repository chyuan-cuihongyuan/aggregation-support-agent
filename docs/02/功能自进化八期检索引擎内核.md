# 功能自进化八期：AW 簇 检索引擎内核（searchkernel）

> 工单 0396-0404（AW1-AW9），借鉴 meilisearch 59.3K / typesense 26.6K / quickwit 11.6K 思想，Java 自研轻量内核。

## 能力面

- **AW1 索引文档生命周期**（0396）：添加/更新（版本严格递增，旧版本 VersionConflict 拒绝）/删除（墓碑：保留记录检索不可见）；倒排表随写随建随删；快照导出（按 id 序）与重建等价。
- **AW2 分词器子集**（0397）：连续字母数字段整词、CJK 每字一词、空白标点切分；小写+全角折半归一；确定性与空输入边界。
- **AW3 容错拼写**（0398）：编辑距离≤分档阈值（≤4 词 0 / 5-8 词 1 / >8 词 2，可配），Levenshtein DP 早停；前缀匹配（首词不容错）；候选按（距离,字典序）排序。
- **AW4 排序规则管道**（0399）：words/typo/proximity/attribute/position/exactness 六级规则（可配序）字典序比较；决胜规则可解释（逐规则独立比较输出首条分出高下的规则名）。
- **AW5 facet 分布**（0400）：分类字段计数分布（计数降序同数键序，键形 field:value）+ 数值字段 stats（min/max/avg）；多字段独立、空结果空分布。
- **AW6 同义词扩展**（0401）：单向（仅 from→tos）/双向（组内互达）规则，多跳层级可配，访问集防环；表入参注入热加载。
- **AW7 查询解析器**（0402）：普通词/引号短语/前缀*/-排除/facet:值过滤子句；引号未闭合降级普通词+告警；非法过滤子句忽略+告警。
- **AW8 高亮定位**（0403）：首命中词级边界（子串不误伤：两侧须非字母数字 CJK）+ 前后 N 字符截断（越界省略号）；无命中回头部截断 hitStart=-1。
- **AW9 搜索索引表与端点**（0404）：search_index_doc 第 25 表双方言 DDL + 守卫；SearchController 四端点（index GET/POST、index/{docId} DELETE、query GET，typesense multi-search 接口面子集），searchkernel.enabled 默认关。

## 配置开关

| 开关 | 默认 | 说明 |
|------|------|------|
| `searchkernel.enabled` | false | 开启才注册 SearchController；不动 ES 既有链路 |
