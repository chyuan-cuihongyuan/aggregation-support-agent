# 功能自进化八期：AV 簇 文档智能内核（docintel）

> 工单 0387-0395（AV1-AV9），借鉴 PaddleOCR 89.6K / docling 66.4K / marker 39.8K / unstructured 15.4K 思想，Java 自研轻量内核。

## 能力面

- **AV1 XY-cut 递归版面分析**（0387）：元素框 Y/X 投影找空白带递归切分（≥阈值才切）→ 层次版面树（内部节点含切分轴/叶挂元素）；空页/单元素边界。
- **AV2 阅读顺序**（0388）：通栏元素（宽度≥全栏阈值）优先按 Y，其余按 X 区间重叠聚栏（带间距容差）→ 栏间左先、栏内 Y/X 序线性化。
- **AV3 表格结构重组**（0389）：单元格 Y/X 区间聚类成行/列段，宽跨≥1.8 列宽占连续列（合并格留痕），表头首行启发可关，缺格补空。
- **AV4 多源 OCR 框融合**（0390）：IoU≥阈值归簇（NMS 按置信度保留序），簇内文本 HIGHEST/WEIGHTED_VOTE（同文本置信度求和）两策略，贡献来源标注。
- **AV5 版面→Markdown**（0391）：标题层级映射/段落/管道表格（表头+分隔行）/图注斜体，管道符转义；序列化确定性可重放。
- **AV6 文档指纹与版面 diff**（0392）：块规范化（去空白+全角折半+小写）SHA-256 指纹序列，LCS diff → MOVED（同指纹异位）/REMOVED/ADDED 三类留痕；同文档 diff 为空。
- **AV7 字段抽取**（0393）：schema（锚点/类型/枚举域/必填）锚点定位 → 右侧取值（默认）或下方就近 → NUMBER/DATE/ENUM/ANY 校验 → HIT/MISS/TYPE_MISMATCH 三态留痕。
- **AV8 版面质量记分**（0394）：覆盖率/重叠率（惩罚）/单调率/表格完整度四指标加权（权重归一可配）→ A/B/C 评级 + 短板说明。
- **AV9 解析任务与端口**（0395）：IDocParsePort + RecordedDocParser（docintel.enabled 默认关；录制样本回放一致/规则合成兜底）；doc_parse_task 第 24 表双方言 DDL + 守卫。

## 配置开关

| 开关 | 默认 | 说明 |
|------|------|------|
| `docintel.enabled` | false | 开启才装配 RecordedDocParser；真实 PDF/图像解析引擎挂雾 |
