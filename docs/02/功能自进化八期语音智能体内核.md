# 功能自进化八期：AU 簇 语音智能体内核（speech）

> 工单 0379-0386（AU1-AU8），借鉴 openai/whisper 109.2K / SYSTRAN/faster-whisper 25.4K / m-bain/whisperX 24.1K 思想，Java 自研轻量内核。

## 能力面

- **AU1 VAD 能量门限**（0379）：高/低双门限滞回（抖动信号不抖段）+ 最短语音段（不足丢弃）+ 最短静音间隙（不足合并），帧区间 [start,end) 输出。
- **AU2 标点恢复**（0380）：长停顿句号/中停顿逗号/疑问词尾问号/句长上限强制断句；规则参数可配；已带标点词幂等跳过。
- **AU3 逆文本归一化 ITN**（0381）：中文数字（含万级/点分小数）→阿拉伯数字、百分之 X→X%、X月X日、单位读法；规则表按优先级应用，无规则透传。
- **AU4 词级时间戳对齐**（0382）：按词字符长比例分配段内时间戳（末词兜底段尾），可选跳过词零长占位；单调性校验（start≤end 且单调不减）违规拒绝。
- **AU5 说话人轮转**（0383）：能量阶跃（上跳与跌变 max/min 比）×基频跳变联合判定变化点，近距抖动取最强防抖，SPEAKER_00/01 交替标签，变化点留痕。
- **AU6 字幕导出**（0384）：SRT（逗号毫秒）与 VTT（WEBVTT 头/点号毫秒）双格式，说话人 `<v>` 标签；SRT 解析回读往返一致；小时进位边界。
- **AU7 转写质量指标**（0385）：WER 词错误率（编辑距离对齐 S/D/I 操作计数回溯）与 CER 字符级；空参考/空假设边界（全对/全错）。
- **AU8 ASR 执行端口**（0386）：IAsrExecutorPort（音频引用→段序列，语言/词级时间戳/说话人选项）+ infrastructure 规则合成假实现（录制样本库回放一致）；speech_transcript 第 23 表双方言 DDL + 守卫；speech.enabled 默认关（真实 ASR 挂雾）。

## 配置开关

| 开关 | 默认 | 说明 |
|------|------|------|
| `speech.enabled` | false | 开启才装配 RuleBasedAsrExecutor；真实 ASR 服务端口化待接 |
