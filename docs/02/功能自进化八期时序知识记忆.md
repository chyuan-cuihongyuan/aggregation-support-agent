# 功能自进化八期：AS 簇 时序知识记忆（tmemory）

> 工单 0362-0370（AS1-AS9），借鉴 mem0 65.3K / graphiti 30.9K / letta 24.7K 思想，Java 自研轻量内核。

## 能力面

- **AS1 双时间线记忆边模型**（0362）：事实边携带 validFrom/validTo（事实时间）与 ingestSeq（事务时间单调序号）；工厂校验（非空三元组/区间/置信度域/类别）+ 显式失效（SUPERSEDED/CONFLICT）。第 22 表 tmemory_edge 双方言 DDL + 方言守卫（TmemoryDdlTest）。
- **AS2 实体消解与归并**（0363）：名称归一键（去空白+小写+全角折半）×类型一致×别名表→归并组+边端点重定向（成员统一重定向到组规范名，自映射保证幂等）；别名环检测。
- **AS3 矛盾检测与失效**（0364）：同主谓宾语不同→冲突裁决（置信度→时间新近→序号），败者打失效戳=胜者生效时间+CONFLICT 原因；三元组全等→去重不失效（保留最高置信度）。
- **AS4 as-of 双口径查询**（0365）：VALID 事实视图（失效边界开区间）/INGESTED 事务视图（含已失效）；逐边可见性解释（ACTIVE/NOT_YET/INVALIDATED）+ 两口径差异集。
- **AS5 情景沉淀晋升**（0366）：时间窗分组→情节摘要（ISummaryPort 端口，异常模板兜底）→跨窗稳定事实（≥阈值窗）晋升 SEMANTIC 边（带晋升来源窗批次）；纯函数重放幂等。
- **AS6 混合检索**（0367）：种子实体 BFS 邻域（跳数可配）图通道 × 关键词覆盖词通道 → RRF 融合（k=60）× 时间衰减（半衰期可配）→ TopK 带通道标注。
- **AS7 冲突仲裁**（0368）：默认加权策略（置信度×新鲜度×来源权威，权威表可配）+ 策略端口插拔；裁决依据留痕；并列按时间新近→序号打破。
- **AS8 压缩与快照**（0369）：失效归档/低价值裁剪（访问频率×分数阈值，SEMANTIC 保护）；MiniSnapshotCodec 零依赖快照编解码（确定性序列化+自描述解析），重放重建等价。
- **AS9 Web 契约**（0370）：TmemoryController 五端点基线（edges 写读/view/search/snapshot，tmemory.enabled 默认关）；聚合 web tmemory-api 封装 + tmemory-contract.test.ts 契约断言（防漂移哨兵）。
