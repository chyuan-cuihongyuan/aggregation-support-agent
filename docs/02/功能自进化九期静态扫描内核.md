# 功能自进化九期：静态扫描内核（工单 0451-0458）

> 九期 [0415 地图](../../issues/0415-wayfinder-map-capability-self-evolution-9.md) BC 簇收官（聚合 scankernel 新域）。借鉴 semgrep 16.7K（规则 DSL/metavariable/污点模式/抑制标注），stars 经 GitHub API 2026-09-17 认证核实。domain 层零框架依赖，全部纯函数内核+端口；只读借鉴不改 Mimosa 链路（0417-D6），scan-kernel.enabled 默认关。

## 二、联动与开关

- 组合管线：BC1 规则解析 → BC2/BC3 模式匹配与绑定 → BC4 污点 → BC5 抑制基线 → BC6 报告 → BC7 清单落库；BC8 为统一入口。
- 纯函数内核不接任何真实扫描链路，scan-kernel.enabled 默认关零行为变化。

## 三、DDL

- 聚合库第 29 表 `scan_finding`（id 主键/fingerprint 唯一/rule_id/file_path/line_no/severity/status OPEN\|SUPPRESSED\|BASELINE/snippet/batch_id/update_time 应用层维护 + rule_id+status 索引），双方言同步追加，ScanDdlTest 守卫断言。

## 四、测试与回归

- 域单测 9 例（内核 4 / 治理 5）+ DDL 守卫 2 例，全部绿。
- 关键确定性验证：模式切分同口径命中与 ... 非贪婪、同名绑定冲突失败、污点传播净化不误报、行内/独立注释抑制方向、基线转 BASELINE、topN 排序与 JSON 重放一致、批次跨批复幂等。
