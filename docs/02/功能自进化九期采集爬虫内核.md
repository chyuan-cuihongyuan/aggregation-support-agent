# 功能自进化九期：采集爬虫内核（工单 0419-0426）

> 九期 [0415 地图](../../issues/0415-wayfinder-map-capability-self-evolution-9.md) AY 簇收官（聚合 crawler 新域）。借鉴 firecrawl 181.2K（爬取清单/正文抽取/markdown 化/节流）、crawl4ai 83.7K（robots 合规/URL 归一/广度调度/链接抽取），stars 经 GitHub API 2026-09-17 认证核实。domain 层零框架依赖，全部纯函数内核+端口+录制假实现；不接真实网络（0417-D2 合规边界），crawler.enabled 默认关。

## 一、八票能力面

| 工单 | 能力 | 内核 |
|------|------|------|
| 0419 AY1 | robots.txt 合规判定 | RobotsJudge：User-agent 分组（精确组优先于 `*` 组）/Allow-Disallow 最长匹配（同长 Allow 优先）/通配 `*` 与行尾 `$` 锚定/Crawl-delay 解析；空文本全放行 |
| 0420 AY2 | URL 归一化去重指纹 | UrlNormalizer：scheme/host 小写/默认端口剥离（80/443）/路径空段折叠尾斜杠归一/查询参数排序+去 utm_* 追踪参数/剥 fragment；规范化串 SHA-256 指纹；仅 http/https、缺 host 拒绝 |
| 0421 AY3 | 广度调度队列 | BreadthScheduler：深度分层 FIFO×域内优先级降序出队/全局指纹去重/最大深度与容量上限拒绝 |
| 0422 AY4 | 令牌桶节流 | TokenBucketThrottle：每域独立桶（容量/速率可配，时钟端口注入）/惰性填充不超容量/未配置域共享默认桶/拒绝时给出等待毫秒估算 |
| 0423 AY5 | 正文抽取去噪 | ContentExtractor：script/style/nav/footer/header 噪声剪除/块级切分文本密度×(1-链接密度)评分/低于阈值剪除/title 抽取/全噪声空结果标记 |
| 0424 AY6 | 链接抽取 | LinkExtractor：a[href] 提取/相对路径（./ ../ / //）按 base 解析绝对化/mailto·javascript·#anchor 过滤/归一去重保序 |
| 0425 AY7 | 爬取清单与状态机 | 第 26 表 crawl_url 双方言（指纹唯一/深度/优先级/PENDING→FETCHED\|FAILED/重试计数/内容指纹）+ CrawlerDdlTest 守卫；CrawlUrlStateMachine：重试计数达上限转 FAILED、终态拒绝转移 |
| 0426 AY8 | 抓取执行端口 | FetchPort + ReplayFetchAdapter 录制回放假实现（未录制 URL 返回 NOT_RECORDED）+ robots→调度→节流→抓取→抽取组合管线（合成三页站点离线全流程） |

## 二、联动与开关

- 组合管线：AY1 robots 判定 → AY3 调度（指纹去重+深度上限）→ AY4 节流 → AY8 抓取 → AY5 正文/AY6 链接 → AY7 清单落库。
- 纯函数内核未接任何采集链路，crawler.enabled 默认关零行为变化；真实网络驱动挂雾（0417-D2）。

## 三、DDL

- 聚合库第 26 表 `crawl_url`（id 主键/fingerprint 唯一/raw_url/domain/depth/priority/status/retry_count/content_hash/fetched_at/update_time 应用层维护 + status+depth 索引），双方言同步追加，CrawlerDdlTest 守卫断言。

## 四、测试与回归

- 域单测 8 例（合规 3 / 管线 5）+ DDL 守卫 2 例，全部绿。
- 关键确定性验证：robots 通配与锚定边界、同长 Allow 优先、URL 多形态同指纹、令牌桶时钟注入填充、三页站点组合管线（/private 被 robots 拦下从未入队）。
