> 九期 [0415 地图](../../issues/0415-wayfinder-map-capability-self-evolution-9.md) AZ 簇收官（聚合 codeintel 新域）。借鉴 Aider-AI/aider 49.0K（search-replace 块/unified diff 应用/repo map/编辑检查点），stars 经 GitHub API 2026-09-17 认证核实。domain 层零框架依赖（不引 tree-sitter，字符串/行级轻量解析，0417-D3），全部纯函数内核+端口；codeintel.enabled 默认关。

## 一、八票能力面

| 工单 | 能力 | 内核 |

| 0427 AZ1 | 仓库地图 | RepoMapper：路径/行数/语言后缀分类→目录聚合行数→每文件一行紧凑摘要（关键符号 class/interface/def 粗筛≤3）+ 字符预算超限按目录省略 |
| 0428 AZ2 | search-replace 块解析 | SearchReplaceParser：`<<<<<<< SEARCH`/`=======`/`>>>>>>> REPLACE` 多块解析，未闭合/缺结束标记拒绝带行号，空文本拒绝 |
| 0429 AZ3 | search-replace 应用 | SearchReplaceApplier：精确唯一命中替换/多命中拒绝报告命中数/行级空白宽容滑窗匹配/幂等跳过（REPLACE 恰好存在一次） |
| 0430 AZ4 | unified diff 解析应用 | UnifiedDiffKernel：`@@ -x,n +y,m @@` hunk 解析计数校验/旧块（上下文+删除行）整体锚定+期望位置±窗口漂移匹配/反向 apply 往返等价/hunk 错序拒绝 |
| 0431 AZ5 | 代码切片 | CodeSlicer：声明行粗筛（def/function/class/签名）→花括号配平切函数体（python 冒号缩进块回退）→目标行定位所属函数→前后文窗口行号前缀渲染 |
| 0432 AZ6 | 括号配平 | BraceBalancer：三类括号栈配平/字符串转义与行/块注释豁免/缺失闭括号报开括号行号+多余闭括号报告 |
| 0433 AZ7 | 编辑会话检查点 | EditSession：检查点栈（编辑前状态）/undo 回滚 redo 前进/容量淘汰最旧/新文件检查点隔离 redo |
| 0434 AZ8 | 编辑审计 | 第 27 表 codeintel_edit 双方言（edit_id 唯一/策略/成功/失败清单 JSON/检查点 id/耗时）+ CodeIntelDdlTest 守卫 + EditAuditPort 内存实现（按文件查询/时间升序/到达序自增 id） |

## 二、联动与开关

- 组合管线：AZ1 repo map 提供上下文 → AZ2/AZ4 解析编辑 → AZ3/AZ4 应用 → AZ6 配平校验 → AZ7 检查点兜底 → AZ8 审计留痕。
- 纯函数内核未接任何代码执行链路，codeintel.enabled 默认关零行为变化；真实语法树解析挂雾（0417-D3）。

## 三、DDL

- 聚合库第 27 表 `codeintel_edit`（id 主键/edit_id 唯一/file_path/strategy/success/errors_json/checkpoint_id/cost_ms/update_time 应用层维护 + file_path+create_time 索引），双方言同步追加，CodeIntelDdlTest 守卫断言。
